# 🎵 节拍器 Metronome

一个基于 Python 的桌面节拍器小工具，通过电脑扬声器播放节拍声音。独立图形界面，无需安装任何第三方依赖。

![Python](https://img.shields.io/badge/Python-3.10%2B-blue) ![Platform](https://img.shields.io/badge/Platform-Windows-green) ![License](https://img.shields.io/badge/License-MIT-yellowgreen)

## ✨ 功能特性

- **独立图形界面**：基于 tkinter 的桌面窗口，无需浏览器或终端
- **速度调节**：BPM 范围 40 ~ 240，滑块实时调节
- **声音频率调节**：37 ~ 4000 Hz，可自由调整节拍音调
- **持续时间调节**：10 ~ 500 ms，控制每个节拍音的长度
- **试听功能**：一键试听当前设置的节拍音，无需启动
- **定时开启**：设定时间后自动启动节拍器，支持 `HH:MM` / `HH:MM:SS`
- **状态栏**：实时显示运行状态、当前参数、定时信息
- **零依赖**：仅使用 Python 标准库（tkinter、winsound、threading）

## 📦 环境要求

- **操作系统**：Windows（`winsound` 为 Windows 专属模块）
- **Python**：3.10 及以上（需自带 tkinter，官方安装包默认包含）

## 🚀 使用方法

### 方式一：双击启动（推荐）

直接双击 `metronome.bat`，将以无终端窗口方式启动图形界面。

### 方式二：命令行启动

```bash

```

## 🔧 核心实现

### 音频播放

使用 Windows 内置 `winsound.Beep(frequency, duration)` 直接驱动扬声器发声，无需音频文件或第三方库。

### 节拍引擎

`MetronomeEngine` 类在后台守护线程中循环播放：

```
每拍间隔 = 60000 / BPM 毫秒
播放 beep → 补足剩余睡眠时间 → 下一拍
```

使用 `threading.Event` 实现精确的停止控制与睡眠中断。

### 定时开启

基于 `threading.Timer`，在指定时间点自动触发节拍器启动。若设定时间已过当天，则自动顺延到次日。

## ⌨️ 操作说明

| 操作 | 说明 |
|------|------|
| 拖动滑块 | 实时调节 BPM / 频率 / 时长（播放中也可调节） |
| **▶ 开始** | 以当前参数开始播放节拍 |
| **■ 停止** | 停止播放 |
| **🔈 试听** | 播放一声当前设置的节拍音 |
| **设定定时** | 输入 `HH:MM` 或 `HH:MM:SS`，到点自动开启 |
| **取消定时** | 取消已设定的定时任务 |

## ⚠️ 注意事项

- 本工具仅支持 **Windows** 系统（依赖 `winsound` 模块）
- 节拍频率范围受限于 `winsound.Beep`（37 ~ 32767 Hz）
- Python 安装时需包含 `tcl/tk` 组件（官方默认安装包已包含）
